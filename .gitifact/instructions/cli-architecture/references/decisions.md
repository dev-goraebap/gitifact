# CLI 결정 표

여러 기능에 걸친 구조 결정이다. 한 기능 안의 결정은 그 기능 설계(`.gitifact/spec/<기능>/design/overview.md`)의 결정 표에 있다. 결정이 바뀐 경위는 `pnpm cli docs history <ID>`와 Git 이력(옛 위키 ADR 0001~0011)에 있다.

## 패키지 경계

```text
apps/cli            명령 실행, Git·파일 접근, 로컬 HTTP 서버
apps/browser        React 브라우저 앱과 정적 빌드
packages/core       문서·이력 규칙과 유스케이스(순수 함수)
packages/contracts  버전이 있는 외부 DTO·검증 계약
packages/intro      언어별 제품 소개 글
```

의존은 `apps/browser → contracts, intro`, `apps/cli → core, contracts` 방향으로만 둔다. 패키지는 `apps`를 참조하지 않고, 앱끼리 소스를 import하지 않으며, exports로 공개한 진입점만 쓴다. 브라우저는 `core`를 가져오지 않는다.

## 결정

| 결정 | 이유 | 기각한 안 |
| :--- | :--- | :--- |
| `apps`(실행·배포 단위)와 `packages`(공개 API가 있는 코드 단위)로 나눈 pnpm TypeScript 모노레포로 둔다. TypeScript strict·ESM, 단일 lockfile, 검증은 zod 계약·node:test·Playwright | CLI와 브라우저가 같은 기록 규칙과 계약을 쓰지만 실행 환경이 다르다. 대가는 계약 변경마다 버전을 올리는 비용과, 경계를 넘기려면 공개 API를 설계해야 하는 것이다 | 추가 모노레포 도구(빌드 병목이 생기기 전), 빈 계층을 미리 만들기 |
| 외부로 나가는 데이터는 contracts의 버전 있는 스키마로만 내보내고 필드 추가도 버전을 올린다 | CLI 출력과 HTTP 응답을 같은 DTO로 검증하고, 받는 쪽이 모르는 모양을 받지 않게 한다 | 버전 없는 JSON |
| Node.js 24와 Git이 있는 로컬에서 동작하고 관리 단위는 Git 저장소 하나다. 외부 요청은 npm 레지스트리 최신 버전 조회 하나뿐이다 | 외부 서비스와 계정 없이 쓰고 프로젝트 정보가 밖으로 나가지 않는다 | 멀티 레포 통합, 원격 협업 기능 |
| 브라우저는 로컬 서버의 계약만 읽는 읽기 전용이다. CLI 프로세스를 실행하거나 파일 시스템에 접근하지 않는다 | 기록의 정확성과 사용자 변경 보존이 가장 중요하고, 기록은 에이전트가 CLI로 남긴다 | 브라우저 편집 |
| npm 패키지 `gitifact` 하나에 CLI 번들, 브라우저 정적 빌드, 언어별 지침·패치노트를 담는다. 자동 기록은 자동 커밋·푸시·설치 권한이 아니다 | 설치된 CLI가 workspace 원본이나 개발 서버 없이 동작한다 | 패키지를 나눠 배포 |
| 에이전트 지침의 편집 원본은 `apps/cli/src/shared/i18n/<lang>/docs/` 하나다. `init`이 지침 파일에 요약 블록을 쓰고 `guide show <topic>`이 원문을 낸다. 블록이 AGENTS.md에 들어가고 Claude용 지침 파일이 없으면 `@AGENTS.md` 한 줄짜리 CLAUDE.md를 만든다. 이 저장소 블록도 `pnpm cli init`이 쓴다 | 지침이 한 곳에서 고쳐지고 CLI 버전과 함께 배포된다. 대가는 블록을 짧게 유지해야 하는 것과 지침 준수를 CLI가 강제할 수 없는 것이다 | 제품 지침을 도구별 스킬 파일로 배포(도구마다 발동 여부가 갈렸다), 블록 마커 사이 직접 편집 |
| 문서는 경로·제목과 독립적인, CLI가 발급한 ID로 식별한다(`S-`·`R-`·`D-`·`W-`·`I-`, 이유 `H-`) | 이름을 바꾸거나 옮겨도 이력과 이유가 이어진다. 대가는 ID를 손으로 만들지 않고 `docs new`로 받아야 하는 것이다 | 파일 이름을 ID로 쓰기(사람이 읽는 slug를 택함), 경로로 식별 |
| 변경 이유는 커밋 시점(`changes commit`)에 최종 변경의 ID에 연결하고, 커밋된 이유는 고치지 않는다 | 초안 단계의 모든 수정이 아니라 실제로 남은 변경에 이유가 붙는다 | 저장할 때마다 이유 기록 |
| 기록 규칙은 core에 순수 함수로 두고 CLI와 서버가 같은 규칙을 쓴다. 파일 쓰기는 임시 파일·잠금·재검사·복구 자료로 사용자 변경을 보존한다 | 두 진입점의 판정이 어긋나지 않고, 실패해도 사용자 파일이 남는다 | 명령마다 규칙 복제 |
| 문서 하나가 파일 하나다: 기능 `index.md`(S-), `requirements/<slug>.md`(R-), `design/<slug>.md`(D-, `overview.md` 필수), 프로젝트 지침 `.gitifact/instructions/<이름>/index.md`(I-) | 에이전트가 필요한 문서만 열고, 옮기거나 제목을 바꿔도 파일 이동·수정일 뿐이다. 대가는 파일 수가 늘고(기능 9개에 요구사항 45, 설계 19) 설계 절과 요구사항의 짝이 파일 단위로 굵어진 것이다 | 요구사항 여러 개를 한 파일에 두고 프론트매터 목록으로 나누기, SQLite 원본(커밋마다 통째 저장, 병합 도구 필요, diff 없음) |
| 구조 정보는 프론트매터에만 둔다. 소속은 폴더로 정하고 본문은 CLI가 파싱하지 않는다 | 형식 규칙이 프론트매터와 경로에만 있어 검사가 단순하다 | 본문 제목·HTML 주석에서 구조 뽑기(0.7 방식), `part_of` 같은 관계 필드 |
| 저장 명령 없이 에이전트가 파일을 직접 고치고, `docs check`와 커밋 직전의 같은 검사가 형식을 본다 | 에이전트가 일반 파일처럼 다룬다. 대가는 "읽은 뒤 바뀌었으면 저장 거부" 같은 보호가 없어진 것이다 | `spec save`가 stamp를 대조해 대신 쓰기 |
| 이유는 `.gitifact/history.jsonl` 한 파일에 `{id, docs, reason}` 한 줄씩 두고 `merge=union`으로 합친다. 10MB(약 25,000줄)를 넘으면 나누기를 다시 검토한다(6,300줄 2.3MB를 13ms에 읽음) | squash 병합이나 PR 제목만 쓰는 설정에서도 남고 일반 clone에 따라온다 | 커밋 메시지 트레일러(squash·편집으로 사라짐), git notes(기본으로 push·fetch 안 됨), 별도 ref(기본 clone에 없음), 고아 브랜치(코드 커밋과 끊김), Change-Id(squash에서 끊김), 이유마다 조각 파일(보류) |
| 형식 번호는 schemaVersion 3이다. 0.7 프로젝트는 CLI가 변환하지 않고 에이전트가 `guide show migrate`로 옮기며 전환 커밋에 `Gitifact-Migration: 0.8.0`을 붙인다. 그 이전 이력은 1.0.0까지 0.7 파서로 읽는다 | 변환 코드를 제품에 두지 않고 옛 ID와 이유 문장을 그대로 잇는다 | CLI 변환 스크립트 |
| CLI와 브라우저 서버가 캐시 `.gitifact/cache/index.db` 하나를 `node:sqlite` WAL로 함께 쓴다. 문서·참조·검색 색인·커밋별 변경을 두고 바뀐 문서와 새 커밋만 다시 읽는다 | 캐시 없이 문서 1,000개 목록 896ms·5,000개 4.0초였고 캐시로 124ms·323ms. 역참조와 이력은 Git 호출이 필요하다. 대가는 worktree마다 처음 한 번 다시 읽는 것(이 저장소 2.85초)과, 5,000개 기준 첫 생성 22초·원문의 약 3.5배 크기(본문 trigram 색인, 줄이는 방법 미결)다 | 캐시 없이 매번 파일 읽기, `.git/gitifact/index.sqlite` 색인(옛 결정) |
| 캐시는 파생물이다. 지우거나 형식 번호가 다르거나 손상되면 다시 만들고, 폴더 안의 `.gitignore`(`*`)로 커밋에서 뺀다. 루트 `.gitignore`는 건드리지 않는다. 커밋의 소스 파일 목록은 캐시에 넣지 않고 서버 메모리에 200커밋까지 둔다 | 원본은 파일과 Git이라 캐시를 잃어도 잃는 것이 없다 | 소스 파일 목록을 캐시에 넣기(형식 번호 변경과 전체 재생성) |
| 패키지마다 `t()`와 문구 폴더를 둔다 | 공용 패키지는 core에 의존성을 만들고 문구를 코드에서 멀어지게 한다. 패키지마다 `t()`를 두는 중복을 감수한다 | 공용 locales 패키지 |
