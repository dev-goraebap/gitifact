## 맥락

0.8.6에서 요구사항을 유즈케이스 3.0 방식으로도 쓸 수 있게 한다. 이 저장소는 요구사항을 이 방식으로 관리하기로 했고(사용자 결정), CLI 지원 전에 원하는 모양으로 보이는지 기능 하나씩 바꿔 확인한다. 지금 CLI는 `style` 키를 모르는 키로 막는다.

## 결정

요구사항은 사용자 스토리 → 범위와 제약 → 사전 조건 → 기본 흐름 → 대체 흐름(A1…, 갈라지는 단계 표시) → 사후 조건 → 수용 조건으로 쓰고, 수용 조건마다 `경로:` 줄로 지나는 흐름을 적는다. 기능 `index.md`에 유즈케이스 모델을 Mermaid로 그린다. 선테스트 동안은 `style: usecase` 키를 붙이지 않는다.

## 검토한 대안

- 한꺼번에 51개 전환(흐름을 실제 동작과 대조하지 못한 채 쓰기 쉽다)
- 고칠 때만 전환(사용자가 지금 기능 하나씩 보고 정하기로 했다)
