## 맥락

위키를 대신할 기능으로 처음에는 에이전트 스킬(SKILL.md, 에이전트 스킬 폴더의 Junction 링크, 작업 시점 알림)을 설계·구현했다. `npx skills`는 원본을 `.agents/skills`에 복사하고 사본을 링크해 원본 수정이 반영되지 않았고, `skills-lock.json`과 원격 측정이 따라와 링크를 직접 구현했었다. 사용자와 논의해 보니 AGENTS.md에 "이 작업 때 이 지침을 읽는다"는 짧은 규칙을 두면 에이전트가 가장 확실히 따르므로 스킬 발견 기능이 필요 없었다.

## 결정

지침은 에이전트 스킬이 아니라 gitifact 문서 종류로 다룬다(사용자 결정). 에이전트 스킬 배포는 `npx skills` 같은 다른 도구의 몫으로 두고, 에이전트마다 다른 폴더·링크를 맞추는 복잡도를 지지 않는다. 지침은 스크립트를 다루지 않는다. 작업 시점에 CLI가 해당 지침을 알리는 조회와 조건 필드(`on`·`paths`)는 사용자가 보류했다.

## 검토한 대안

- SKILL.md 표준 형식과 에이전트 폴더 링크(`skills sync`, Junction, exclude 관리)(AGENTS.md의 짧은 규칙이 더 확실해 스킬 발견이 필요 없고, 에이전트마다 폴더·링크를 맞추는 복잡도가 생긴다)
