## 맥락

`core.autocrlf=true`로 복제하면 LF로 커밋된 문서가 CRLF로 checkout된다. 이때 건드리지 않은 명세가 바뀐 것으로 잡혀 커밋이 미선택 변경으로 거부된 결함이 있었다. 0.8.0 문서 형식은 파서가 CRLF를 LF로 읽는다.

## 결정

문서 비교는 CRLF를 LF로 맞춘 원문으로 하고, 줄바꿈만 다른 문서는 변경으로 보지 않는다. 어떤 파일을 커밋할지는 Git 상태가 정한다. staging된 원문이 작업 파일과 같거나 줄바꿈만 다를 때만 허용하고, 그 밖의 내용을 바꾸는 Git 필터는 거부한다.

## 검토한 대안

- Git blob ID로 비교(0.7 방식. 0.8.0은 문서를 파싱해 ID로 비교하고 파서가 CRLF를 LF로 읽는다)
