## 맥락

입력 파일이 프로젝트에 쌓인다는 건의를 받고 파일 생성 자체를 없애는 방향도 검토했다. 커밋 입력에는 여러 줄 한국어 본문이 들어가는데, 이런 본문은 Windows 셸 인자에서 깨지기 쉽다.

## 결정

커밋 입력에 파일을 쓰는 경로를 남긴다. 파일은 CLI가 알려 준 경로에 쓰고, 커밋에 성공하면 CLI가 지운다. `--file -`로 표준 입력도 받는다.

## 검토한 대안

- 파일 생성을 없애고 인자·표준 입력으로만 받기(여러 줄 한국어 본문이 Windows 셸 인자에서 깨지기 쉽다)
