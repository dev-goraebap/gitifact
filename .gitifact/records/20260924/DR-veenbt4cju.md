## 맥락

에셋은 Git 저장소에 함께 커밋된다. 큰 파일을 저장소에 두는 것은 사용자의 선택이며, 커밋을 막으면 사용자가 제한을 우회하게 된다.

## 결정

에셋 하나 1MB, 전체 50MB, 권장 확장자(png·jpg·jpeg·gif·webp·svg·pdf) 제한은 경고로만 알린다. `docs check`는 문제 뒤에 경고를 따로 보이고 `changes list`는 경고 수를 알린다. 경고는 종료 코드를 바꾸지 않고 커밋도 막지 않는다.

## 검토한 대안

- 한도 초과 시 커밋 거부(사용자가 제한을 우회하게 된다)
