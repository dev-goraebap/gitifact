## 맥락

사용자가 새 버전 안내와 업데이트 명령을 요청했다. 사용자 동의 전에는 버전을 바꾸지 않고, 프로젝트가 지정한 실행 방식(npx·프로젝트 설치·전역 명령)을 유지해야 한다. 설치 방식은 CLI가 소유하지 않고, 자기 교체 설치는 실행 중인 CLI가 자기 파일을 바꿔야 한다.

## 결정

CLI는 설치를 자동으로 하지 않고 새 버전의 실행 명령만 알린다. 기본은 버전을 지정한 npx 명령이고 npm 전역 설치 명령은 선택지로 함께 준다. 동의 뒤의 갱신은 에이전트가 프로젝트 실행 방식으로 새 CLI의 `update`를 실행해 한다.

## 검토한 대안

- 자기 교체 설치(`update --apply`)(설치 방식을 CLI가 소유하지 않고, 실행 중 자기 파일을 바꿔야 한다)
- 브라우저 요청으로 명령을 실행하는 경로
