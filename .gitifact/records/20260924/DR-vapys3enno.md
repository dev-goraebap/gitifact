## 맥락

미커밋 명세 변경은 문장 대신 Git 상태 메뉴의 경고 점과 Git 상태 페이지 배너로 알린다. 첫 구현은 셸이 명세 API를 불렀는데, 명세 저장소가 없는 프로젝트의 Git·소개 화면에서 503 오류가 콘솔에 남았다.

## 결정

작업 중 변경 표시는 명세 API를 스스로 부르지 않고 명세 Query 캐시와 Git 상태 응답으로만 판단한다. 캐시만으로는 Git 상태 페이지에 바로 들어올 때 표시가 비어, 모든 페이지가 이미 읽는 Git 상태 응답의 `.gitifact/` 아래 변경 경로를 두 번째 출처로 더했다.

## 검토한 대안

- 셸에서 명세를 조회(명세 저장소가 없는 프로젝트에서 503 오류가 남음)
