## 맥락

0.8.3 블록은 전역 설치를 "제안"하게 했다. 한 사용자의 Claude Code 자동 모드 세션에서 검사기가 에이전트의 `npm install -g gitifact`를 검증되지 않은 외부 코드 도입으로 막았고, 에이전트는 사용자에게 직접 설치하라고 넘겼다. 사용자가 터미널에서 쳤지만 Windows PowerShell의 스크립트 실행 제한으로 `npm.ps1`도 막혔다. 문서상 자동 모드는 사용자 메시지가 동작을 구체적으로 가리키면 약한 차단을 푼다. 이 저장소 세션에서 정확한 명령을 담아 묻고 "네"만 받았을 때 같은 전역 설치가 통과했다(2026-09-27, 한 번 시험).

## 결정

사용자에게 설치를 떠넘기지 않는다(사용자 결정). 에이전트는 설치·업데이트 명령을 그대로 보여 주며 실행해도 되는지 묻고, 허용받으면 직접 실행한다. 도구가 그래도 막으면 그 도구의 승인 창이나 권한 설정으로 승인을 받는다. Windows PowerShell에서 스크립트가 막히면 `npm.cmd`·`gitifact.cmd`로 실행한다. 블록·workflow 지침·시작하기가 같은 절차를 안내한다.

## 검토한 대안

- 설치가 막히면 사용자에게 명령을 주고 기다리기(가장 나쁜 경험이라 사용자가 기각)
- npx 대안을 블록에 되살리기(호출마다 느리고, 외부 코드를 받아 실행하므로 같은 검사에 걸릴 수 있다)
