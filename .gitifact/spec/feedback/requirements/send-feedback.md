Gitifact를 쓰는 사용자로서, GitHub 이슈 양식을 따로 찾아 쓰지 않고도 도구의 버그와 개선 제안을 개발자에게 전하기 위해 대화에서 부탁하면 에이전트가 이슈를 대신 남겨 주기를 바란다.

### 범위와 제약

- 사용자 프로젝트의 요구사항이 아니라 Gitifact라는 도구에 대한 의견만 다룬다.
- 본문 끝에 자동으로 붙이는 것은 Gitifact·운영체제·Node 버전과 저장 규약 버전뿐이다. 프로젝트 파일이나 문서 내용은 넣지 않는다.
- GitHub 토큰을 받거나 보관하지 않는다.

### 사전 조건

- 사용자와 에이전트가 대화 중이고, 에이전트가 `gitifact`를 실행할 수 있다.

### 기본 흐름

1. 사용자가 대화에서 Gitifact의 버그나 개선을 남겨 달라고 부탁한다.
2. 에이전트가 종류(버그·개선)와 제목·본문 초안을 사용자에게 보여 준다.
3. 사용자가 초안을 확인한다.
4. 에이전트가 초안을 입력 파일에 쓰고 `feedback`을 실행한다.
5. 시스템은 본문 끝에 환경 정보를 붙여, 사용자의 `gh`로 Gitifact 저장소에 이슈를 만든다.
6. 시스템은 이슈 주소를 보이고, 에이전트가 사용자에게 알린다.

### 대체 흐름

- **A1. 사용자가 초안을 고치거나 보내지 않기로 함** (3단계에서)
  1. 고쳐 달라고 하면 에이전트가 초안을 고쳐 다시 보이고 3단계로 돌아간다.
  2. 보내지 말라고 하면 아무것도 보내지 않고 끝난다.
- **A2. 보내기 전에 미리 봄** (4단계에서)
  1. 에이전트가 `feedback --dry-run`을 실행한다.
  2. 시스템은 보낼 방법과 제목, 환경 정보를 붙인 본문을 보이고 아무것도 보내지 않는다.
  3. 3단계로 돌아간다.
- **A3. `gh`가 없거나 로그인되어 있지 않음** (5단계에서)
  1. 시스템은 제목과 본문을 채운 새 이슈 작성 페이지 주소를 보인다.
  2. 사용자가 브라우저에서 이슈를 제출한다.
- **A4. `gh`로 이슈 만들기에 실패함** (5단계에서)
  1. 시스템은 실패를 알리고 A3처럼 새 이슈 작성 페이지 주소를 보인다.
- **A5. 본문이 길어 주소에 다 담기지 않음** (A3 1단계에서)
  1. 시스템은 주소의 본문이 잘렸다는 사실과 전체 본문을 함께 보인다.
- **A6. 입력이 틀림** (4단계에서)
  1. 종류가 버그·개선이 아니거나 제목이 비었거나 여러 줄이면, 시스템은 보내지 않고 입력 오류로 알린다.
  2. 에이전트가 입력을 고쳐 4단계부터 다시 한다.

### 사후 조건

- 성공하면 Gitifact 저장소에 이슈가 하나 생기고 사용자가 그 주소를 안다.
- 사용자가 확인하지 않은 초안은 어디에도 보내지 않는다.

### 수용 조건

1. 경로: 기본 흐름
   조건: `gh`가 로그인된 상태에서 사용자가 초안을 확인합니다.
   기대 동작: 사용자 계정으로 Gitifact 저장소에 이슈가 만들어지고 이슈 주소가 출력됩니다. 본문 끝에 환경 정보가 붙습니다.
2. 경로: 기본 흐름, A1
   조건: 사용자가 초안을 보고 보내지 말라고 합니다.
   기대 동작: 에이전트가 `feedback`을 실행하지 않고, 아무것도 보내지 않습니다.
3. 경로: 기본 흐름, A2
   조건: 보내기 전에 미리 봅니다.
   기대 동작: 보낼 방법과 제목, 환경 정보를 붙인 본문을 보이고 아무것도 보내지 않습니다.
4. 경로: 기본 흐름, A3
   조건: `gh`가 없거나 로그인되어 있지 않습니다.
   기대 동작: 제목과 본문을 채운 새 이슈 작성 페이지 주소가 출력됩니다.
5. 경로: 기본 흐름, A3, A5
   조건: `gh`가 없고 본문이 주소에 다 담기지 않을 만큼 깁니다.
   기대 동작: 잘렸다는 사실과 전체 본문이 함께 출력됩니다.
6. 경로: 기본 흐름, A4
   조건: `gh`는 로그인되어 있지만 이슈 만들기에 실패합니다.
   기대 동작: 실패를 알리고 새 이슈 작성 페이지 주소가 출력됩니다.
7. 경로: 기본 흐름, A6
   조건: 종류가 버그·개선이 아니거나 제목이 비었거나 여러 줄입니다.
   기대 동작: 보내지 않고 입력 오류로 알립니다.
