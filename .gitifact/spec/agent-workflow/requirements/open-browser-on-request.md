개발 도구에 익숙하지 않은 사용자로서, 요구사항과 프로젝트 현황을 읽기 쉬운 화면으로 확인하기 위해 보여 달라고 말하면 에이전트가 브라우저 주소를 알려 주기를 원한다.

### 범위와 제약

지침 블록과 작업 흐름 문서가 이 요청을 `browser` 명령과 연결한다. 명령은 URL을 출력한 뒤 서버로 계속 실행되므로 에이전트는 백그라운드로 실행한다. 기본 브라우저를 자동으로 여는 기능은 포함하지 않는다. CLI는 에이전트가 지침을 따르는지 검증하지 않는다.

### 수용 조건

1. 조건: 사용자가 요구사항·프로젝트 현황·변경 이력·패치노트를 보여 달라고 합니다.
   기대 동작: 에이전트는 `browser`를 백그라운드로 실행하고 출력된 URL을 알려 줍니다. 명세 JSON을 읽어 채팅에 요약하는 것으로 대신하지 않습니다.
2. 조건: 같은 대화에서 이미 띄운 서버가 실행 중입니다.
   기대 동작: 새로 띄우지 않고 그 URL을 다시 알려 줍니다.
