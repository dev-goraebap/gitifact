# 기여자 조회 요구사항

## Git 작성자별 참여 조회
<!-- gitifact-req: R-ybmsjjgqtp -->

프로젝트 Git 이력에서 기여자를 추려 기능별 참여와 관련 활동을 보여준다. author와 committer는 구분하며 커밋 작성자를 요구사항 요청자나 승인자로 단정하지 않는다.

### 수용 조건

1. 조건: 사용자가 기여자를 선택합니다.
   기대 동작: 관련 기능과 활동을 보고 작성자로 필터링한 요구사항 이력으로 이동할 수 있습니다. 이메일 기반 아바타는 외부 서비스 없이 생성합니다.

2. 조건: 활동·제품 기능·상세 등 어느 화면에서든 기여자 아바타나 이름을 누릅니다.
   기대 동작: 해당 기여자의 상세 페이지로 이동합니다. 기여자 목록은 아바타·이름·이메일·커밋 수·참여 기능 수·최근 활동을 카드로 보여주고, 상세 페이지는 큰 아바타와 참여한 기능, 불러온 명세 활동을 보여줍니다.
