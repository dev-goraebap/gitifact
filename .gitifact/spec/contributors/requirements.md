# 참여자 조회 요구사항

## Git 작성자별 참여 조회
<!-- gitifact-req: R-ybmsjjgqtp -->

프로젝트 참여자로서, 누가 어떤 기능의 변경에 참여했는지 파악하기 위해 Git 작성자별 참여 기능과 관련 활동을 확인하고 싶다.

### 범위와 제약

프로젝트 Git 이력에서 참여자를 추려 기능별 참여와 관련 활동을 보여준다. author와 committer는 구분하며 커밋 작성자를 요구사항 요청자나 승인자로 단정하지 않는다. 화면 이름은 참여자이며 기여도를 평가하는 표현으로 쓰지 않는다.

### 수용 조건

1. 조건: 사용자가 참여자를 선택합니다.
   기대 동작: 관련 기능과 활동을 보고 작성자로 필터링한 요구사항 이력으로 이동할 수 있습니다. 이메일 기반 아바타는 외부 서비스 없이 생성합니다.

2. 조건: 활동·제품 기능·상세 등 어느 화면에서든 참여자 아바타나 이름을 누릅니다.
   기대 동작: 해당 참여자의 상세 페이지로 이동하며 주소는 참여자 목록 아래의 고유 경로입니다. 참여자 목록은 아바타·이름·이메일·커밋 수·참여 기능 수·최근 활동을 카드로 보여주고, 상세 페이지는 큰 아바타와 참여한 기능, 최근 명세 활동을 보여줍니다. 참여자 화면에는 이력 개수나 이전 이력 더 보기 안내를 두지 않습니다.
