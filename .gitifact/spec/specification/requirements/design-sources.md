설계를 쓰는 에이전트와 읽는 참여자로서, 설계가 어떤 프로젝트 지침과 외부 자료에 근거했는지 한눈에 보기 위해 참고 문서를 본문 곳곳의 링크가 아니라 목록으로 관리하고 싶다.

### 범위와 제약

- 참고 문서는 설계 파일 프론트매터의 `sources` 목록이다.
- 저장소 안의 문서는 `{id, note?}`로 ID만, 외부 자료는 `{title, url, note?}`로 적는다.
- 외부 페이지의 제목이나 미리보기는 가져오지 않는다.

### 기본 흐름

1. 에이전트가 설계 파일의 프론트매터에 `sources`를 적는다.
2. 에이전트가 `check`로 확인한다.
3. `specs list`와 `specs show`가 참고 문서를 제목과 함께 보여 준다.
4. 참여자가 브라우저에서 설계 탭을 연다.
5. 참고 문서가 설계 본문 아래에 한 줄씩 목록으로 보인다.
6. 참여자가 항목을 누르면 저장소 안의 문서는 해당 화면으로, 외부 자료는 새 탭으로 열린다.

### 대체 흐름

- **A1. `sources`의 형식이 맞지 않음** (2단계에서)
  1. `check`가 문제로 알리고 커밋을 거부한다.
- **A2. `sources`의 id가 없는 문서를 가리킴** (2단계에서)
  1. `check`가 없는 참조로 알리고 커밋을 거부한다.

### 수용 조건

1. 경로: 기본 흐름
   조건: 설계 파일의 프론트매터에 sources를 적습니다.
   기대 동작: `specs list`와 `specs show`가 참고 문서를 제목과 함께 보여 줍니다.
2. 경로: 기본 흐름, A1
   조건: sources의 형식이 맞지 않습니다.
   기대 동작: `check`가 문제로 알리고 커밋을 거부합니다.
3. 경로: 기본 흐름, A2
   조건: sources의 id가 없는 문서를 가리킵니다.
   기대 동작: `check`가 없는 참조로 알리고 커밋을 거부합니다.
4. 경로: 기본 흐름
   조건: 브라우저에서 설계 탭을 봅니다.
   기대 동작: 참고 문서가 설계 본문 아래에 한 줄씩 목록으로 보이고, 저장소 안의 문서는 해당 화면으로, 외부 항목은 새 탭으로 연결됩니다.
