Gitifact 브라우저를 쓰는 사용자로서, 지금 어떤 버전으로 보고 있는지 알기 위해 화면에서 실행 중인 CLI 버전을 확인하고 싶다.

### 기본 흐름

1. 사용자가 브라우저를 연다.
2. 시스템은 세션 정보를 받으면 메뉴에 실행 중인 CLI 버전을 보인다.
3. 사용자가 버전을 누른다.
4. 시스템은 패치노트를 연다.

### 대체 흐름

- **A1. 세션 정보를 아직 받지 못함** (2단계에서)
  1. 시스템은 버전 자리를 비워 두고 임의의 버전을 보이지 않는다.

### 수용 조건

1. 경로: 기본 흐름
   조건: 브라우저가 세션 정보를 받았습니다.
   기대 동작: 실행 중인 CLI 버전이 보이고, 누르면 패치노트로 갑니다.
2. 경로: 기본 흐름, A1
   조건: 세션 정보를 받기 전입니다.
   기대 동작: 임의의 버전을 보이지 않습니다.
