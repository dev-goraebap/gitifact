Gitifact를 업데이트한 사용자로서, 무엇이 달라졌는지 파악하기 위해 버전마다 추가·변경·제거·수정된 내용을 시간순으로 보고 싶다.

### 범위와 제약

- 패치노트는 설치한 CLI에 함께 들어 있어, 네트워크 없이 설치된 버전까지의 기록만 보인다.

### 기본 흐름

1. 사용자가 브라우저에서 패치노트를 연다.
2. 시스템은 최신 버전부터 버전·날짜와 추가·변경·제거·수정 항목을 시간순으로 보인다.
3. 시스템은 지금 실행 중인 버전을 표시한다.

### 대체 흐름

- **A1. 요청한 언어의 패치노트가 없음** (2단계에서)
  1. 시스템은 기본 언어의 패치노트를 보이고, 다른 언어로 대체됐다고 알린다.

### 수용 조건

1. 경로: 기본 흐름
   조건: 사용자가 패치노트를 엽니다.
   기대 동작: 최신 버전부터 버전·날짜와 추가·변경·제거·수정 항목이 보이고, 실행 중인 버전이 표시됩니다.
2. 경로: 기본 흐름, A1
   조건: 요청한 언어의 패치노트가 없습니다.
   기대 동작: 기본 언어의 패치노트를 보이고 대체됐다고 알립니다.
