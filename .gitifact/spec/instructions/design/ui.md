## 메뉴와 경로

WORKSPACE 메뉴의 "기능별 요구사항" 아래에 "프로젝트 지침"을 둔다. 브라우저는 위키를 보이지 않으며, 과거 위키 페이지의 변경은 결정기록 목록과 커밋 페이지에서 제목만 보인다.

| 경로 | 화면 |
| :--- | :--- |
| `/instructions` | 목록 |
| `/instructions/agents` | AGENTS.md |
| `/instructions/<I-ID>?file=<경로>` | 지침 상세. `file`이 없으면 `index.md` |

## 목록

"상시 지침" 아래에 AGENTS.md 한 줄, "작업별 지침 N개" 아래에 지침마다 한 줄을 폴더 이름 순으로 둔다. 64rem 중앙 컬럼이고 바깥 상자와 표 머리는 두지 않으며, 줄 사이는 얇은 선으로 나눈다. 줄 전체가 상세로 가는 링크다.

| 줄의 부분 | 내용 |
| :--- | :--- |
| 색 표지 | 지침 고유 색의 둥근 사각형과 제목 첫 글자. AGENTS.md는 색 없는 테두리 표지 |
| 첫 줄 | 제목을 굵게, 그 옆에 폴더 이름을 옅은 글자로 |
| 둘째 줄 | `description` 한 줄(길면 자름). AGENTS.md는 "모든 세션이 먼저 읽는 지침" |

지침 색은 프로젝트의 지침 전체를 폴더 이름 순으로 보며 정한다. 지침마다 ID를 FNV-1a로 해시한 색에서 시작해, 앞 지침이 쓴 색이면 다음 색으로 넘긴다. 그래서 8개까지는 서로 다른 색이고, 같은 지침 구성이면 목록·상세 어디서나 같은 색이다. 팔레트는 Astryx 색 토큰(blue·green·purple·orange·teal·pink·cyan·yellow)이고, 빨강은 오류·제거의 뜻이라 뺐다. 제목과 폴더 이름이 한 줄에 놓여야 해서 Astryx ListItem(제목이 문자열 하나) 대신 링크 한 줄로 그린다. 둘 다 없으면 AGENTS.md와 지침을 만드는 방법을 안내한다.

## 상세

| 부분 | 내용 |
| :--- | :--- |
| 머리 | 목록으로 가는 "← 프로젝트 지침" 링크, 색 표지·제목·설명, 폴더 이름·ID·최근 변경, "이 지침의 활동" 링크 |
| 파일 목록 | 왼쪽 열(14rem). `index.md`가 맨 위에 지침 제목으로, 이어서 폴더마다 파일과 크기. Markdown 파일은 첫 `# ` 제목으로, 제목이 없거나 Markdown이 아니면 파일 이름으로 보인다. 폴더는 펼친 채 시작하고 폴더 이름을 눌러 접는다. 고른 파일에 표시 |
| 내용 | 위에 파일의 저장소 경로. Markdown은 DocumentBody로 그리고, 링크는 그 파일 기준으로 해석해 같은 지침의 파일·다른 지침·AGENTS.md로 잇는다. 그 밖의 텍스트는 CodeBlock(확장자로 언어), 이진·큰 파일은 이유만 |
| 관계 | 본문 아래 RelatedList. 이 지침을 `sources`로 가리키는 설계 |

AGENTS.md 화면은 머리("← 프로젝트 지침" 링크, 경로·최근 변경)와 본문 문서뿐이다. 1024px보다 좁으면 파일 목록이 내용 위에 온다. 파일을 고르면 주소의 `file`이 바뀌어 뒤로가기로 돌아온다.

결정기록 목록에서 지침 변경은 문서 종류 배지 `지침`(cyan)으로 보이고, 커밋 페이지와 기록 상세의 지침 변경은 현재 지침으로 잇는다. 검색창도 지침을 찾는다. 코드는 `pages/instructions`다.
