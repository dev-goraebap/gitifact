프로젝트 참여자로서, 이 프로젝트에 어떤 작업 방식이 있고 에이전트가 언제 무엇을 따르는지 알기 위해 브라우저에서 AGENTS.md와 작업별 지침을 훑고 지침 하나를 파일까지 읽고 싶다.

### 범위와 제약

- AGENTS.md는 저장소 루트의 파일을 문서로 보인다.
- Markdown 파일은 문서처럼 그리고, 그 밖의 텍스트 파일은 원문으로 보인다.

### 기본 흐름

1. 사용자가 프로젝트 지침 메뉴를 연다.
2. 시스템은 AGENTS.md를 맨 위에, 작업별 지침을 그 아래 폴더 이름 순으로 보인다. 지침마다 표지·제목·폴더 이름·설명이 있고, 같은 지침은 목록과 상세에서 같은 표지다.
3. 사용자가 지침 하나를 연다.
4. 시스템은 `index.md`를 문서로 보이고, 옆에 그 폴더의 파일 목록을 보인다.
5. 사용자가 파일을 골라 읽고, 본문의 상대 링크로 같은 지침의 파일, 다른 지침, AGENTS.md로 간다.

### 대체 흐름

- **A1. AGENTS.md를 엶** (3단계에서)
  1. 시스템은 AGENTS.md 본문을 문서로 보이고, 그 안의 지침 링크를 누르면 해당 지침을 연다.
- **A2. AGENTS.md와 지침이 모두 없음** (2단계에서)
  1. 시스템은 어떻게 만드는지 안내한다.
- **A3. 없는 지침이나 AGENTS.md를 엶** (4단계에서)
  1. 시스템은 찾을 수 없음 상태와 목록 링크를 보인다.
- **A4. Markdown이 아닌 파일을 고름** (5단계에서)
  1. 시스템은 그 파일을 원문으로 보인다.

### 수용 조건

1. 경로: 기본 흐름
   조건: 사용자가 프로젝트 지침 메뉴를 엽니다.
   기대 동작: AGENTS.md가 맨 위에, 작업별 지침이 폴더 이름 순으로 보이고, 지침끼리 표지가 겹치지 않으며 같은 지침은 목록과 상세에서 같은 표지입니다.
2. 경로: 기본 흐름
   조건: 사용자가 지침 하나를 열고 본문의 상대 링크를 누릅니다.
   기대 동작: `index.md`가 문서로 보이고 옆의 파일 목록에서 하위 파일을 고를 수 있으며, 링크는 같은 지침의 파일·다른 지침·AGENTS.md로 연결됩니다.
3. 경로: A1
   조건: 사용자가 AGENTS.md를 열고 그 안의 지침 링크를 누릅니다.
   기대 동작: AGENTS.md 본문이 문서로 보이고, 링크한 지침이 열립니다.
4. 경로: 기본 흐름, A2
   조건: AGENTS.md와 지침이 모두 없습니다.
   기대 동작: 어떻게 만드는지 안내합니다.
5. 경로: 기본 흐름, A3
   조건: 없는 지침 ID로 들어옵니다.
   기대 동작: 찾을 수 없음 상태와 목록 링크를 보여 줍니다.
6. 경로: 기본 흐름, A4
   조건: 지침 폴더의 텍스트 설정 파일을 고릅니다.
   기대 동작: 원문 그대로 보입니다.
