프로젝트 참여자로서, 현재 결정의 배경을 이해하고 이후 변경을 판단하기 위해 위키 페이지의 변경 내용과 이유를 확인하고 싶다.

### 범위와 제약

위키 페이지의 변경은 요구사항과 같은 방식으로 Git에 남는다. 커밋 시점의 변경 전후를 비교하고 변경 이유를 페이지 ID에 연결해 다른 문서의 이유와 같은 `.gitifact/history.jsonl`에 쌓는다.

### 수용 조건

1. 조건: 페이지를 수정하거나 옮기고 커밋합니다.
   기대 동작: 활동 페이지에 종류(위키)·추가·변경·이동·제거와 변경 전후 본문, 기록된 이유가 나타납니다. 이유가 없으면 미기록 상태를 안내합니다.
2. 조건: 이미 커밋된 페이지 변경 이유를 고치거나 지우려 합니다.
   기대 동작: 요구사항의 이유와 같이 거부합니다. 과거 원문은 Git 커밋에서 읽습니다.
