프로젝트 참여자로서, 변경의 작성자를 확인하고 이력을 오해하지 않기 위해 실제 Git 작성자와 기록에 근거한 활동 표시를 보고 싶다.

### 범위와 제약

타임라인은 항목마다 Git author 기반 로컬 아바타를 세로 선 위에 표시한다. 같은 요구사항의 변경을 잇는 관계 그래프는 두지 않으며, Git 브랜치 병합이나 무관한 요구사항을 관계로 꾸미지 않는다.

### 수용 조건

1. 조건: 이력 목록을 표시합니다.
   기대 동작: Git author 이름과 이메일 기반 로컬 아바타를 표시합니다. 요구사항·설계 사이의 관계를 선이나 그래프로 꾸며내지 않습니다.

2. 조건: 다른 참여자의 작업 브랜치가 병합된 뒤 활동·개요·위키 변경 이력을 확인합니다.
   기대 동작: 원본 작업 커밋의 작성자·변경 이유를 표시합니다. 단순 병합은 같은 변경을 다시 집계하지 않으며 작성자 필터와 검색도 원본 커밋을 기준으로 합니다.

3. 조건: 병합 중 충돌을 해결하거나 문서를 추가로 수정합니다.
   기대 동작: 병합 과정에서 수정한 기록은 병합 커밋의 작성자로 남기고, 다른 브랜치에서 그대로 가져온 기록은 원본 작성자로 유지합니다.

4. 조건: 스쿼시 또는 리베이스로 원본 커밋이 현재 브랜치 이력에 남아 있지 않습니다.
   기대 동작: 현재 Git 이력에 남은 커밋의 author를 표시하며 사라진 작성자를 추측하지 않습니다.
