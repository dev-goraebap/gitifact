Gitifact 사용자로서, 제품의 소스와 공개 안내를 찾아볼 수 있도록 브라우저에서 GitHub 저장소를 열고 싶다.

### 범위와 제약

- 링크 대상은 https://github.com/dev-goraebap/gitifact 하나다.
- 새 탭으로 열고 지금 프로젝트 화면은 그대로 둔다.

### 기본 흐름

1. 사용자가 사이드바 하단의 GitHub 로고 링크를 고른다.
2. 브라우저가 저장소를 새 탭에서 연다.

### 대체 흐름

- **A1. 모바일 탐색 메뉴** (1단계에서)
  1. 사용자가 모바일 탐색 메뉴를 열고 같은 링크를 고른다.
- **A2. 키보드나 스크린 리더로 탐색함** (1단계에서)
  1. 링크를 GitHub 저장소 링크로 식별할 수 있다.

### 수용 조건

1. 경로: 기본 흐름
   조건: 사이드바 하단의 GitHub 로고 링크를 선택합니다.
   기대 동작: https://github.com/dev-goraebap/gitifact 를 새 탭에서 열고 현재 프로젝트 화면은 유지합니다.
2. 경로: A1, A2
   조건: 모바일 탐색 메뉴를 엽니다.
   기대 동작: 같은 GitHub 링크를 사용할 수 있으며 키보드와 스크린 리더로 링크를 식별할 수 있습니다.
