Gitifact 사용자로서, 제품의 소스와 공개 안내를 찾아볼 수 있도록 브라우저에서 GitHub 저장소를 열고 싶다.

### 수용 조건

1. 조건: 사이드바 하단의 GitHub 로고 링크를 선택합니다.
   기대 동작: https://github.com/dev-goraebap/gitifact 를 새 탭에서 열고 현재 프로젝트 화면은 유지합니다.

2. 조건: 모바일 탐색 메뉴를 엽니다.
   기대 동작: 같은 GitHub 링크를 사용할 수 있으며 키보드와 스크린 리더로 링크를 식별할 수 있습니다.
