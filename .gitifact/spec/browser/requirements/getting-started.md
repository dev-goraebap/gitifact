Gitifact 사용자로서, 도입과 개발 중 사용법을 선택한 언어로 확인하기 위해 브라우저 뷰어 안에서 시작하기 안내를 읽고 싶다.

### 수용 조건

1. 조건: 사용자가 메뉴의 소개 바로 아래에서 시작하기를 선택합니다.
   기대 동작: 선택한 언어로 설치·도입, 개발·커밋 요청 예시, 프로젝트 지침 만들기, 문서 조회, 업데이트와 직접 실행할 CLI 명령을 읽습니다.

2. 조건: 사용자가 소개 본문의 CLI 안내 링크를 선택하거나 시작하기 주소를 직접 열고 새로고침합니다.
   기대 동작: 같은 시작하기 페이지를 엽니다. 프로젝트에 명세가 없어도 안내를 읽을 수 있습니다.

3. 조건: 사용자가 좁은 화면이나 라이트·다크 모드에서 안내를 읽습니다.
   기대 동작: 기존 문서 화면과 같은 레이아웃으로 본문과 복사 가능한 명령·프롬프트를 제공합니다.

4. 조건: 전역 설치 없이 직접 명령 실행 예시를 사용합니다.
   기대 동작: 일상 명령은 npx gitifact로, 처음 도입·업데이트는 @latest로 안내합니다. 사용자용 예시에는 --yes나 버전 자리표시자를 반복하지 않습니다. 에이전트는 지침의 지정 버전을 사용하며 프로젝트 설치는 선택 사항으로 제공합니다.
