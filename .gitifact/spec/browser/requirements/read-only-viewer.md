프로젝트 참여자로서, 원본을 바꾸지 않고 현재 작업의 기록을 확인하기 위해 조회 상태를 구분할 수 있는 읽기 전용 브라우저를 사용하고 싶다.

### 범위와 제약

- 브라우저는 React·Astryx와 프로젝트 프론트엔드 지침을 따른다.
- 조회로 원본을 수정하지 않고 worktree·세션을 구분한다.
- 색인과 캐시는 다시 만들 수 있고, 작업 폴더와 git status에 나타나지 않는다.
- 폰트와 빈 화면 일러스트는 외부 서비스 요청 없이 로컬에서 보인다.
- 성능 목표는 실제 측정값과 함께 보고한다.

### 기본 흐름

1. 참여자가 브라우저를 연다.
2. 브라우저가 로딩만 보이다가, 준비되면 첫 화면을 보인다.
3. 참여자가 다른 화면으로 이동한다.
4. 새 화면의 데이터가 준비될 때까지 지금 화면을 유지한 채 로딩을 보이고, 준비되면 새 화면을 한 번에 보인다.

### 대체 흐름

- **A1. 짧은 조회** (4단계에서)
  1. 로딩을 깜빡이지 않고 바로 새 화면을 보인다.
- **A2. 결과가 비었거나 조회가 실패함** (2단계나 4단계에서)
  1. 빈 결과·검색 결과 없음·오류를 구분해 안내한다. 변경과 오류를 숨기지 않는다.
- **A3. 에이전트가 문서를 고치거나 커밋한 뒤 탭으로 돌아옴** (4단계 뒤)
  1. 화면은 그대로 두고 새 변경이 있다는 알림과 새로 고침을 보인다. 변경이 없으면 알림을 보이지 않는다.
  2. 참여자가 새로 고침을 누르면 지금 상태로 다시 읽고, 그동안 기존 내용을 유지한다.
- **A4. 불러온 이력을 두고 다른 화면에 다녀옴** (3단계에서)
  1. 불러온 이력이 그대로 남고 서버에 다시 묻지 않는다.
  2. 다시 읽는 시점은 새로 고침뿐이며, 그때는 불러온 페이지를 모두 다시 읽는다.
- **A5. 서버를 다시 띄우거나 새 커밋이 생김** (2단계에서)
  1. 이미 읽은 이력은 다시 읽지 않고 새 커밋만 더 읽는다.
  2. 색인이 지워지거나 손상됐으면 다음 조회 때 다시 만든다.
- **A6. 검색창에 한글을 조합해 입력함** (4단계 뒤)
  1. 조합 중인 글자가 끊기거나 겹쳐 쌓이지 않고 입력한 그대로 보이며, 그 검색어로 목록이 좁혀진다.

### 수용 조건

1. 경로: 기본 흐름, A2
   조건: 사용자가 최초 조회·재조회하거나 파일이 바뀝니다.
   기대 동작: 최신 목록부터 읽고 재생성 가능한 Git 제외 색인과 캐시를 활용합니다. 변경과 오류를 숨기지 않으며 로딩·빈 결과·오류를 구분합니다.
2. 경로: 기본 흐름, A1
   조건: 데이터 조회가 진행됩니다.
   기대 동작: 짧은 조회에는 로딩을 깜빡이지 않습니다. 다른 화면으로 이동할 때는 새 화면의 데이터가 다 준비될 때까지 지금 화면을 유지한 채 로딩을 보이고, 준비되면 새 화면을 한 번에 보입니다. 처음 접속할 때는 로딩만 보입니다.
3. 경로: A3
   조건: 브라우저를 연 채로 에이전트가 문서를 고치거나 커밋한 뒤, 사용자가 브라우저 탭으로 돌아옵니다.
   기대 동작: 화면은 그대로 두고 새 변경이 있다는 알림과 새로 고침을 보입니다. 새로 고침을 누르면 지금 상태로 다시 읽습니다. 변경이 없으면 알림을 보이지 않습니다.
4. 경로: A4
   조건: 이력을 더 불러온 뒤 다른 화면에 갔다가 돌아옵니다.
   기대 동작: 불러온 이력이 그대로 남아 있고 서버에 다시 묻지 않습니다. 다시 읽는 시점은 새로고침뿐이며, 그때는 불러온 페이지를 모두 다시 읽습니다.
5. 경로: A5
   조건: 브라우저 서버를 다시 띄우거나 새 커밋이 생긴 뒤 이력을 엽니다.
   기대 동작: 이미 읽은 이력은 다시 읽지 않고 새 커밋만 더 읽습니다. 이 색인은 작업 폴더와 git status에 나타나지 않으며, 지우거나 손상돼도 다음 조회 때 다시 만들어집니다.
6. 경로: A6
   조건: 사용자가 검색창에 한글을 입력기로 조합해 입력합니다.
   기대 동작: 조합 중인 글자가 끊기거나 겹쳐 쌓이지 않고 입력한 그대로 보이며 그 검색어로 목록이 좁혀집니다.
7. 경로: 기본 흐름
   조건: 사용자가 브라우저를 탐색합니다.
   기대 동작: 로고와 어울리는 두꺼운 제목 폰트와 메뉴별 Hugeicons 아이콘을 제공합니다. 폰트와 빈 화면 일러스트는 외부 서비스 요청 없이 로컬에서 표시합니다.
