Gitifact를 처음 접하는 사용자로서, 저장소나 npm에서 영어 안내를 읽고 필요하면 한국어 원문으로 이동하고 싶다.

### 범위와 제약

- 영어 문서는 한국어 소개와 시작하기의 의미와 범위를 그대로 옮긴다.
- 번역 서비스를 호출하지 않는다.

### 기본 흐름

1. 사용자가 저장소나 npm 패키지의 README를 연다.
2. 영어 문서가 기본으로 보이고, 한국어 문서로 가는 링크가 있다.
3. 사용자가 링크를 눌러 한국어 원문을 읽는다.

### 대체 흐름

- **A1. 오프라인으로 설치해 읽음** (1단계 대신)
  1. 설치한 패키지에 한국어·영어 메시지·에이전트 지침·패치노트·브라우저 안내가 함께 들어 있다.

### 수용 조건

1. 경로: 기본 흐름
   조건: npm 패키지 페이지에서 README를 엽니다.
   기대 동작: 영어 문서가 보이고 한국어 문서 링크가 있습니다.
2. 경로: 기본 흐름
   조건: 영어 README와 한국어 소개를 비교합니다.
   기대 동작: 소개와 시작하기의 의미와 범위가 같습니다.
3. 경로: A1
   조건: 네트워크 없이 패키지를 설치해 두 언어로 안내를 읽습니다.
   기대 동작: 두 언어의 안내가 모두 있고 번역 서비스를 호출하지 않습니다.
