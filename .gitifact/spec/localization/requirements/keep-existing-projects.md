기존 Gitifact 사용자로서, 표시 언어를 바꾸거나 CLI를 업데이트해도 프로젝트 기록과 지침을 계속 사용하고 싶다.

### 수용 조건

1. 조건: 같은 저장 규약(schemaVersion 3)의 프로젝트에서 CLI를 올리거나 표시 언어를 바꾼 뒤 조회·초기화·업데이트합니다.
   기대 동작: 도입 기준선·ID·요구사항·설계·지침·결정기록을 그대로 씁니다. 저장 규약이 바뀐 버전이면 문서를 건드리지 않고 전환 절차(`guide show migrate`)를 안내합니다.

2. 조건: 언어를 명시하지 않고 기존 GITIFACT 블록을 갱신합니다.
   기대 동작: 기존 언어를 유지합니다. 언어 토큰이 없는 과거 블록은 한국어로 읽습니다. --lang을 명시하면 해당 언어로 갱신하고 마커 밖 내용은 보존합니다.

3. 조건: 새 프로젝트에 도입합니다.
   기대 동작: 새 블록은 선택한 CLI 언어로 생성합니다. 이후 표시 언어 변경은 기존 사용자 문서를 번역하지 않습니다.
