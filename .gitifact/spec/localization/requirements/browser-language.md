Gitifact 사용자로서, 익숙한 언어로 화면과 사용 안내를 읽기 위해 브라우저 설정에서 표시 언어를 고르고 싶다.

### 범위와 제약

- 표시 언어는 한국어와 영어다.
- 표시 언어를 바꿔도 프로젝트 문서는 번역하거나 바꾸지 않는다.

### 기본 흐름

1. 사용자가 브라우저를 연다.
2. 저장한 선택이 없으면, 시스템은 브라우저 언어가 한국어일 때 한국어로, 그 밖에는 영어로 보인다.
3. 사용자가 설정에서 한국어·영어·브라우저 설정 중 하나를 고른다.
4. 시스템은 메뉴·화면 문구·컴포넌트 안내·날짜·소개·시작하기·패치노트를 그 언어로 바꾸고, 현재 주소·선택·필터와 프로젝트 문서는 그대로 둔다.
5. 시스템은 선택을 저장하고, 같은 출처의 열린 탭에도 반영한다.

### 대체 흐름

- **A1. 다시 엶** (2단계에서)
  1. 저장한 선택이 있으면 시스템은 그 언어로 보인다.
- **A2. 브라우저 저장소가 막힘** (5단계에서)
  1. 선택을 저장하지 못해도 현재 탭은 고른 언어로 보인다.

### 수용 조건

1. 경로: 기본 흐름
   조건: 한국어 브라우저로 처음 엽니다.
   기대 동작: 한국어로 보입니다. 한국어가 아닌 브라우저에서는 영어로 보입니다.
2. 경로: 기본 흐름
   조건: 결정기록 목록에 필터를 건 채 설정에서 영어를 고릅니다.
   기대 동작: 화면 문구와 날짜가 영어로 바뀌고, 주소와 필터, 프로젝트 문서는 그대로입니다.
3. 경로: 기본 흐름
   조건: 같은 출처의 다른 탭이 열려 있는 상태에서 언어를 바꿉니다.
   기대 동작: 열린 탭에도 같은 언어가 반영됩니다.
4. 경로: 기본 흐름, A1
   조건: 언어를 고른 뒤 같은 주소를 다시 엽니다.
   기대 동작: 고른 언어로 열립니다.
5. 경로: 기본 흐름, A2
   조건: 브라우저 저장소 접근이 막혀 있습니다.
   기대 동작: 현재 탭에서는 언어를 고르고 쓸 수 있습니다.
