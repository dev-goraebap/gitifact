# 표시 언어

## 브라우저 언어 선택
<!-- gitifact-req: R-eeyxmpd37g -->

Gitifact 사용자로서, 익숙한 언어로 화면과 사용 안내를 읽기 위해 브라우저 설정에서 표시 언어를 고르고 싶다.

### 수용 조건

1. 조건: 언어를 지정하지 않고 브라우저를 엽니다.
   기대 동작: 브라우저 언어가 한국어이면 한국어로, 그 밖에는 영어로 표시합니다.

2. 조건: 설정에서 한국어·영어·브라우저 설정을 선택합니다.
   기대 동작: 메뉴·화면 문구·컴포넌트 안내·날짜·소개·시작하기·패치노트가 선택한 언어를 따릅니다. 현재 주소·선택·필터와 프로젝트 문서는 유지합니다.

3. 조건: 같은 주소를 다시 열거나 같은 브라우저의 다른 탭에서 언어를 바꿉니다.
   기대 동작: 저장한 선택을 유지하고 같은 출처의 열린 탭에 반영합니다. 저장소 접근이 차단돼도 현재 탭에서 선택할 수 있습니다.

## CLI 언어 선택
<!-- gitifact-req: R-y6gszx7dg6 -->

CLI 사용자로서, 명령과 오류를 이해하기 위해 실행 환경이나 명시한 언어로 안내를 받고 싶다.

### 수용 조건

1. 조건: CLI를 실행합니다.
   기대 동작: 명시한 --lang ko|en을 우선하고, 없으면 GITIFACT_LANG·LC_ALL·LC_MESSAGES·LANG·운영체제 언어 순으로 결정합니다. 한국어 지역 표기를 한국어로 읽고 미지원 언어는 영어로 표시합니다.

2. 조건: 도움말·텍스트 출력·오류·docs를 읽습니다.
   기대 동작: 제품이 제공하는 안내는 선택한 언어를 따르며 명령어·옵션·JSON 키·오류 코드·ID는 바뀌지 않습니다.

3. 조건: 서로 다른 언어의 브라우저가 같은 서버에 요청합니다.
   기대 동작: 각 요청의 표시 언어로 오류를 돌려주고 다른 요청이나 CLI의 언어에 영향을 주지 않습니다.

## 기존 프로젝트 보존
<!-- gitifact-req: R-l2cviw6kk7 -->

기존 Gitifact 사용자로서, 표시 언어를 바꾸거나 CLI를 업데이트해도 프로젝트 기록과 지침을 계속 사용하고 싶다.

### 수용 조건

1. 조건: schemaVersion 2 프로젝트에서 0.7.0으로 조회·초기화·업데이트합니다.
   기대 동작: 저장 규약·도입 기준선·ID·명세·설계·위키·변경 이유는 유지하며 별도 마이그레이션을 요구하지 않습니다.

2. 조건: 언어를 명시하지 않고 기존 GITIFACT 블록을 갱신합니다.
   기대 동작: 기존 언어를 유지합니다. 언어 토큰이 없는 과거 블록은 한국어로 읽습니다. --lang을 명시하면 해당 언어로 갱신하고 마커 밖 내용은 보존합니다.

3. 조건: 새 프로젝트에 도입합니다.
   기대 동작: 새 블록과 기본 위키 방침은 선택한 CLI 언어로 생성합니다. 이후 표시 언어 변경은 기존 사용자 문서를 번역하지 않습니다.

## 영문 기본 배포 문서
<!-- gitifact-req: R-lwzfbzmgi4 -->

Gitifact를 처음 접하는 사용자로서, 저장소나 npm에서 영어 안내를 읽고 필요하면 한국어 원문으로 이동하고 싶다.

### 수용 조건

1. 조건: 저장소 또는 npm 패키지의 README를 엽니다.
   기대 동작: 영어 문서를 기본으로 표시하고 한국어 문서 링크를 제공합니다. 영어 문서는 다듬어진 한국어 소개와 시작하기의 의미·범위를 유지합니다.

2. 조건: 패키지를 오프라인으로 설치해 안내를 읽습니다.
   기대 동작: 한국어·영어 메시지·에이전트 지침·패치노트·브라우저 안내가 함께 제공되며 번역 서비스를 호출하지 않습니다.
