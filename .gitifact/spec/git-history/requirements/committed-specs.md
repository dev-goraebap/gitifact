프로젝트 참여자로서, 반복 편집 중의 초안과 영구 기록을 구분하기 위해 Git에 커밋된 최종 명세를 기준으로 변경 이력을 확인하고 싶다.

### 범위와 제약

작업 중 대화와 반복 수정은 초안 편집이다. 영구 이력은 Git에 커밋된 최종 버전으로 추적한다. 별도 승인 묶음과 note는 사용하지 않는다.

### 수용 조건

1. 조건: 요구사항을 여러 번 편집한 뒤 커밋을 준비합니다.
   기대 동작: 마지막 커밋 대비 최종 차이를 기록합니다. 수정 후 원복됐다면 바뀐 문서로 보지 않으며 결정기록을 요구하지 않습니다.

설계의 생성·수정·삭제·경로 이동도 Git의 최종 문서로 추적한다. 설계만 바뀐 경우 요구사항 변경으로 만들지 않으며 설계는 문서 전체를 변경 단위로 삼는다.
