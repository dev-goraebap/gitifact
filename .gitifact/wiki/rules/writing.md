# 문서 문체

공통 문체는 CLI 내장 지침 `gitifact docs writing`이다. 모든 프로젝트에 해당하는 규칙은 그쪽에 두고 여기에 다시 적지 않는다. 이 페이지에는 이 저장소에만 해당하는 것을 둔다.

- 날짜별 작업·검증·배포 기록은 위키와 명세에 두지 않는다. 그것은 [개발 환경](../../../docs/development.md)과 Git 이력의 몫이다.
- 제품 이름은 Gitifact, 저장 경로는 `.gitifact`로 쓴다. 과거 이름 Tryce와 `.tryce`는 과거 기록을 설명할 때만 쓴다.
- 에이전트 지침의 원본은 `apps/cli/src/shared/i18n/<lang>/docs/`다. 모든 프로젝트에 적용할 규칙을 위키에 적지 않고 그 파일에 적는다.
- 제품의 목적·원칙·범위는 루트 README(원본은 `packages/intro`)에, 구현 규칙과 결정은 이 위키에 둔다.
