# 문서 문체

위키·명세·지침 문서를 쓰는 방식을 정한다.

- 짧고 담백하게 쓴다. 목적과 동작을 먼저 쓰고 근거와 대가를 뒤에 붙인다.
- 문장은 평서형 "~다"로 끝낸다. 명령·권유·감탄을 쓰지 않는다.
- 과장된 확신, 반복 강조, 구호를 쓰지 않는다. "반드시", "절대", "완벽"은 실제 제약일 때만 쓴다.
- 확정된 내용과 제안·미결을 구분한다. 구현되지 않은 것은 계획이라고 표시한다.
- 날짜별 작업 기록은 두지 않는다. 그것은 `docs/`와 Git 이력의 몫이다.
- 같은 것을 다른 이름으로 부르지 않는다. 기존 페이지에서 쓰는 이름을 따른다.
- 표는 비교할 것이 있을 때만 쓰고, 목록은 항목이 서로 대등할 때만 쓴다.
