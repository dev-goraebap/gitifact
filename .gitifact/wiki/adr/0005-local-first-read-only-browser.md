# 결정 0005. 로컬 실행과 읽기 전용 브라우저

상태: Accepted · 2026-09-18

## 맥락

사용자는 기록 명령을 배우지 않고, 에이전트가 CLI로 명세를 저장하며, 사람은 브라우저로 기록을 본다. 기록의 정확성과 사용자 변경의 보존이 가장 중요하다. 이 결정은 이전 ARCHITECTURE.md의 제약·런타임·배포 내용을 옮겨 적은 것이다.

## 결정

Node.js 24와 Git이 있는 로컬 환경에서 동작하고, 외부 요청은 npm 레지스트리의 최신 버전 조회 하나뿐이다. 관리 단위는 Git 저장소 하나다. `gitifact browser`가 로컬 서버를 띄우고, 브라우저는 그 서버의 계약만 HTTP로 읽는다. 브라우저는 읽기 전용이며 CLI 프로세스를 실행하거나 파일 시스템에 접근하지 않는다. npm 패키지 `gitifact` 하나에 CLI 번들, 브라우저 정적 빌드, 언어별 지침·패치노트를 담고, 설치된 CLI는 workspace 원본이나 개발 서버 없이 동작한다. 자동 기록은 자동 커밋·푸시·설치 권한이 아니다.

## 결과

외부 서비스와 계정 없이 쓸 수 있고 프로젝트 정보가 밖으로 나가지 않는다. 대가는 멀티 레포 통합, 브라우저 편집, 원격 협업 기능을 두지 않는 것이다. 기록이 커지면 필요한 범위의 조회와 페이지네이션을 도입하되 서로 다른 관측 시점을 섞지 않는다.
