# 결정 0002. 지침 재정의

상태: 채택 · 2026-09-18

## 맥락

위키와 명세를 무엇을 어떻게 쓸지는 프로젝트마다 다르지만, 저장 형식과 `spec save`의 검증은 모든 프로젝트가 같아야 한다. 사용자가 지침을 삭제하거나 임의로 바꿔도 시스템이 깨지지 않아야 한다.

## 결정

`gitifact docs <topic>`은 CLI가 정한 형식 부분 뒤에 운영 지침을 붙여 출력한다. `.gitifact/overrides/<topic>.md`가 있으면 내장 운영 지침 대신 그 파일을 싣는다. `docs <topic> --eject`가 내장본을 그 경로에 복사하며 기본 상태에는 파일이 없다. 형식 부분과 저장 검증은 재정의와 무관하다. CLI는 재정의 파일의 내용을 판정하지 않고 비어 있으면 경고만 한다.

## 결과

에이전트의 절차(`docs <topic>` 읽기)가 바뀌지 않고, 파일을 지우면 내장 지침으로 돌아간다. 대가는 지침을 topic마다 형식/운영 두 파일로 유지해야 하는 것이다. 기각한 안: 재정의 파일을 에이전트가 따로 읽게 하기(충돌 시 우선순위 판단이 에이전트에 넘어감), 문서 전체를 대체하게 하기(형식 규칙까지 지워 저장이 반복 실패). 폴더 이름은 conventions·rules 대신 overrides를 택했다.
