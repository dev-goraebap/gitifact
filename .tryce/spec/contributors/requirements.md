# 기여자 조회 요구사항

## Git 작성자별 참여 조회
<!-- tryce-req: R-ybmsjjgqtp -->

프로젝트 Git 이력에서 기여자를 추려 기능별 참여와 관련 활동을 보여준다. author와 committer는 구분하며 커밋 작성자를 요구사항 요청자나 승인자로 단정하지 않는다.

### 수용 조건

1. 조건: 사용자가 기여자를 선택합니다.
   기대 동작: 관련 기능과 활동을 보고 작성자로 필터링한 요구사항 이력으로 이동할 수 있습니다. 이메일 기반 아바타는 외부 서비스 없이 생성합니다.
