# 프로젝트 도입 요구사항

## Git 기준선과 초기화
<!-- tryce-req: R-lpwtvv6ldp -->

관리 단위는 하나의 Git 저장소이며 기존 작업·브랜치·worktree 맥락을 존중한다. 초기화는 설정과 도입 기준선만 만든다. 멀티 레포 통합은 범위 밖이다.

### 수용 조건

1. 조건: Git 저장소에 tryce를 처음 도입합니다.
   기대 동작: 모드 없는 설정과 기준선을 생성합니다. 첫 커밋이 없어도 시작할 수 있고, 기존 변경과 staging을 보존하며 초기화로 커밋하지 않습니다.

## 기존 설정과 명시적 전환
<!-- tryce-req: R-rmwolikuep -->

초기화 재실행은 설정·기준선을 덮어쓰지 않는다. 구형 자료를 신규 프로젝트로 오인하지 않는다.

### 수용 조건

1. 조건: 기존 설정이나 구형 기록을 발견합니다.
   기대 동작: 기존 상태를 유지하거나 필요한 전환을 안내합니다. 전환은 합의된 제거 범위에 따라 검증하고 별도 원본 백업을 강제하지 않습니다.

## 현재 세션과 이후 세션의 스킬 연결
<!-- tryce-req: R-b2q2g4sgsd -->

에이전트가 환경과 자연어 지침을 해석하고 CLI가 스킬 파일을 설치한다. 원본만 Git에 보관하고 Claude 복사본은 로컬 생성한다.

### 수용 조건

1. 조건: 사용자가 도입 프롬프트를 전달합니다.
   기대 동작: 기존 AGENTS.md·CLAUDE.md와 수정된 스킬을 보존하고 최소 연결 안내를 추가합니다. 설치한 스킬을 현재 세션에서도 직접 읽습니다.
