# Gitifact 랜딩페이지 설계

이 페이지는 Gitifact를 처음 보는 사람이 에이전트와 계속 개발할 때 무엇이 남고, 나중에 무엇을 다시 볼 수 있는지 이해하도록 돕는다. 제품 기록의 원본은 README와 `.gitifact/spec/`이다.

- 첫 화면: “대화가 끝나도 제품의 맥락은 남는다”는 이점을 보여 주고, 스토리 체험과 시작 명령으로 이동할 수 있게 한다.
- 대표 흐름: 방문자가 다섯 단계를 선택하거나 스크롤하면서 대화, 기능별 요구사항·설계, 프로젝트 지침, 커밋 시점의 이유, 읽기 전용 브라우저를 본다. 단계 선택은 현재 화면에서 즉시 바뀌고 이전 단계로 돌아갈 수 있다.
- 아키텍처: `AGENTS.md`는 언제 지침을 읽을지 알리고, `.gitifact/spec/`과 `.gitifact/instructions/`는 Git 저장소에 있다. 커밋된 최종 문서와 변경 이유는 Git 이력에 연결된다. 브라우저는 읽기 전용이다.
- 시각 방향: 짙은 녹흑 바탕, 연한 초록 포인트, 큰 한글 제목과 작은 고정폭 메타데이터. 제품의 파일·관계·시간을 선과 카드의 이동으로 표현한다. 움직임은 이해를 돕는 단계 전환에 집중한다.
- 상태: 단계 선택과 자동 재생 일시정지는 페이지 내부 상태다. 새로고침 뒤 초기 단계로 돌아간다. 줄임 동작 설정에서는 자동 재생을 끄고 공간 이동을 줄인다.
- 한계: 이 페이지의 스토리·도식은 설명용 예시이며 실제 프로젝트 데이터를 읽지 않는다. 실제 현황은 로컬 `gitifact browser`에서 본다.
