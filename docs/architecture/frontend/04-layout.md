# 프론트엔드 레이아웃

Gentask의 04-layout.md와 Claude의 browser-design-v2/Main.dc.html을 바탕으로 구성한다. 프로토타입의 고정 화면 크기·예시 데이터·이전 파일 형식은 그대로 구현하지 않는다.

앱 전체 골격은 widgets/app-shell, 라우트 연결은 app, 본문은 pages가 소유한다. 셸은 inset 배치를 사용한다. AppShell은 wash 변형으로 왼쪽 메뉴와 바닥을 같은 배경색으로 두고, 본문은 여백·둥근 모퉁이·표면색·테두리·낮은 그림자를 가진 카드 안에 넣는다. 카드가 스크롤 컨테이너이며 메뉴에는 세로 구분선을 두지 않는다. 64rem 미만에서는 여백·모퉁이·그림자를 없애 본문 폭을 유지한다. Astryx의 elevated 변형은 TopNav가 있을 때 모퉁이 하나만 둥글게 하므로 쓰지 않았다. 데스크톱 왼쪽 메뉴는 기본 240px이며 SideNav resizable로 200~400px 사이에서 조절하고 localStorage에 유지한다. 이력·기여자는 목록과 약 26rem의 상세를 배치하지만, 제품 기능은 19~21rem 기능 목록과 남은 폭을 사용하는 명세 본문으로 구성한다. 문서 읽기에 목록 중심의 상세 패널 비율을 재사용하지 않는다. 페이지 헤더는 shared/ui/page-header의 PageHeader로 제목만 한 줄에 두고 하단 보더로 본문과 나눈다. 새로고침처럼 페이지 전체에 걸친 동작은 헤더 오른쪽에 ghost 버튼으로 둔다. 설명 문구·경로·조회 시각은 헤더에 넣지 않고 본문이나 하단 상태 줄에 둔다. 제목 옆 개수 배지는 두지 않는다. 2026-09-15 이전에는 제목·설명·경로를 담은 두꺼운 헤더였으나 사용자 요청으로 단순화했다.

제품 기능은 활동 페이지와 같은 중앙 컬럼을 쓴다. 목록은 Table로 제목·설명·요구사항 수·설계 유무·AvatarGroup 참여자·최근 변경을 두고, 기능을 열면 목록 대신 같은 폭의 상세 페이지가 되며 위에 ← 제품 기능 링크를 둔다. 2026-09-15 이전의 좌측 목록·우측 문서 2단 배치(featureWorkspace)는 inset 카드 안에서 이중 테두리로 보여 제거했다. 본문은 명세 제목·목차·요구사항별 구분과 R-ID를 제공한다. 조건과 기대 동작은 박스 없이 줄을 구분하며, 표시용 줄바꿈 때문에 저장된 원문을 바꾸지 않는다. 테마는 stone을 사용하고 색상·선택·배경은 설치된 토큰을 사용한다.

배치만 바뀌면 CSS, 상호작용이 바뀌면 React 컴포넌트로 처리한다. 모바일 경계는 Astryx 테마의 lg(1024px)와 CSS의 64rem을 일치시킨다. 경계를 바꾸면 두 위치를 함께 수정한다. 좁은 화면에서는 메뉴를 열고 닫을 수 있고 선택한 상세가 목록 대신 본문 폭을 사용한다. 상세를 닫으면 필터를 유지한 목록으로 돌아간다. 데스크톱 목록은 행 기반, 상세는 독립 스크롤을 사용한다. 긴 제목·ID·경로·Markdown이 페이지 전체를 가로로 밀어내지 않도록 한다.

Astryx AppShell·Layout·LayoutPanel·LayoutContent·VStack·HStack을 우선 사용한다. 중복 패딩과 구분선을 줄이고 간격은 토큰을 사용한다. 본문에는 rem을 사용하며 페이지별 zoom이나 root font-size 변경은 하지 않는다.

키보드 내비게이션, 상세 진입과 닫기, 작은 화면, 긴 콘텐츠, 라이트·다크를 검증한다. Gitifact는 읽기 전용이므로 생성 FAB·편집 모달·자동 저장은 포함하지 않는다.

## 활동 타임라인 배치

활동 페이지는 GitLab 활동 피드와 같은 세로 타임라인이다. 본문은 최대 64rem(1024px)의 중앙 컬럼이며, 스크롤 컨테이너는 셸의 콘텐츠 카드 하나뿐이라 스크롤바가 카드 가장자리에 남는다. 카드와 서랍의 스크롤바는 scrollbar-width: thin과 보더 토큰의 scrollbar-color로 얇게 그리며, 이를 지원하지 않는 구형 브라우저는 기본 모양을 쓴다. 컬럼 안에는 제목·필터 줄·타임라인 순서로 놓는다. 제목은 스크롤로 사라지고 필터 줄은 sticky로 상단 바 아래에 고정된다. 이전의 Table 기반 받은편지함 배치와 같은 명세 연결 그래프(HistoryGraph·history-layout·visx)는 2026-09-15에 제거했다. 그래프는 읽기에 도움이 되지 않았고 와이드 화면에서 표가 전체 폭을 차지해 보기 어려웠다.

각 항목은 왼쪽 세로 선 위에 아바타를 놓고, 작성자와 상대 시각(Timestamp), 변경 종류 Token·명세 종류·제목 링크·기능 링크, 커밋 해시와 이유 한 줄을 세 줄로 표시한다. 같은 커밋의 연속 항목도 해시를 그대로 적고 위 여백만 줄인다. 변경 종류 이름은 추가·변경·제거·이동이다. 2026-09-15에 생성·수정·삭제에서 바꿨고, 신규·개정·폐기와 작성·갱신·삭제는 피드 문장과 어울리지 않아 기각했다. 제목 링크가 URL의 selected를 바꿔 상세를 연다. 이유가 없으면 기록되지 않았다고 안내하고 커밋 메시지로 대신하지 않는다. R-ID와 전체 시각은 상세에서 확인한다.

상세는 Astryx Dialog 서랍이다. 1024px 이상에서는 오른쪽 가장자리에 붙는 700px 패널이며 왼쪽 가장자리의 ResizeHandle과 useResizable로 420~1100px 사이에서 너비를 조절하며 autoSaveId로 localStorage에 너비를 유지한다. 그 아래에서는 fullscreen 변형으로 연다. 서랍이 스크롤 컨테이너이고 DialogHeader(제목, 종류·ID·해시 부제, 닫기)는 sticky로 고정된다. 본문은 작성자·시각, 변경 후, 접힌 변경 전, 변경 이유, 현재 기능 링크 순서다. 삭제된 항목의 변경 전은 처음부터 펼친다. 모달이라 열린 동안 목록은 조작할 수 없고 Escape·배경 클릭으로 닫힌다. 이전의 옆 읽기 패널(LayoutPanel)은 중앙 정렬 컬럼과 충돌해 서랍으로 바꿨다.
