# Tryce 프로젝트 자체 도입

2026-09-13 사용자가 도입 프롬프트 정리, 기존 프로젝트 요구사항 도출, 이 저장소의 자동모드 전환과 Tryce 커밋 적용을 요청했다. 지정된 CLI 0.2.1을 사용한다. 기존 prototype-1 설정은 CLI가 백업하고 도입 기준선과 note는 그대로 유지했다. 과거 커밋은 재작성하지 않는다.

## 조사와 등록 범위

사용자 대화, 제품 기준, 기록 정책·요구사항 수집·실행 형식·스킬 배포·세션 브리핑·브라우저 명세, 관련 CLI 명령과 테스트를 함께 확인했다. 문서가 있다는 사실만으로 구현됐다고 판단하지 않았다. 이력의 기준점은 자체 도입 직전 커밋 `3a83e5c`이며 현재 요청으로 추가한 지침 연결·도출 절차는 해당 요청을 근거로 구분했다.

첫 등록은 제품 원칙, 에이전트 도입, 기록 정책, Git 연결, 조회의 주요 조건이다. 모든 과거 문서의 세부 규약이나 예외를 일괄 복제한 목록은 아니다. 배열 상한·HTTP 응답별 조건·아키텍처 세부 선택 등은 기존 명세를 유지하고 해당 영역을 변경할 때 필요에 따라 편입한다. 이슈 트래커 연계는 개발 여부가 미정이므로 요구사항으로 확정하지 않았다. GUI와 전체 이력 검사는 방향만 알려져 있어 구체적인 수용 조건을 정할 초안으로 남긴다.

명확한 사용자 의도와 근거가 일치한 항목은 자동모드에서 Codex가 확정한다. 사용자 승인으로 표시하지 않으며 모든 항목의 구현·검증 상태는 CLI의 `not-assessed`·`not-run`을 유지한다. 실제 실행 검증 결과는 요구사항 활성 상태와 별도로 기록한다.

## 지침 연결

AGENTS.md가 이미 공용 스킬을 연결하고 CLAUDE.md가 AGENTS.md를 읽도록 안내한다. 이 참조를 유지하며 중복 안내나 새로운 CLAUDE.md를 만들지 않았다. README 도입 프롬프트는 지침 파일의 유무와 기존 참조를 확인하고 필요한 연결만 추가하도록 한다. CLI에 지침 파일 생성·동기화 기능을 추가한 것은 아니다.

## 개발 예외와 검증 범위

요구사항·확인 기록은 req 명령을 사용하므로 DEV-01에서 제외하고, 일반 커밋은 commit plan/apply를 사용하므로 DEV-03에서 제외한다. 일반 설계 문서 편집과 미지원 기능의 예외, 기존 Claude 개발 복사본 동기화에 대한 DEV-04는 필요한 범위에서 유지한다. 전체 Git 이력 검사와 훅이 없다는 이유로 일반 커밋까지 계속 우회하지 않는다.

공용 스킬의 형식 검사, 로컬 복사본 동기화·보존 테스트 5개, 배포 패키지의 외부 설치 검증을 통과했다. 도입 전 note 18개의 내용과 기존 기준선이 보존된 것을 확인했다. 지침 파일이 없는 별도 프로젝트에서 새 에이전트가 자율적으로 도입하는 종단 시험과 문서 없는 프로젝트의 요구사항 도출은 이번 자체 적용만으로 검증됐다고 보지 않는다. 갱신한 스킬은 다음 배포에 포함할 소스이며 이미 게시된 0.2.1 패키지를 변경하지 않는다.

## 첫 기록 단위

제품 원칙 2개, 에이전트 도입 3개, 기록 정책 3개, Git 연결 2개, 조회 2개를 자동 확정했다. 요구사항 GUI와 전체 Git 이력 검사 2개는 초안으로 남겼다. 실제 내용과 ID는 `.tryce/spec/<영역>/tryce.json`에서 확인한다. 기존 구현 전체에 완료를 선언하거나 과거 커밋에 참조를 붙이지 않는다.
